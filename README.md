### `> featured operations`

**[security-pre-commit-scanner](https://github.com/hexwrk/security-pre-commit-scanner)** — Git pre-commit hook that blocks insecure code before it hits history. **V2** pairs fast regex pre-filtering with a local **Ollama / qwen2.5-coder:14b** triage layer to cut false positives, so secrets, SQLi, unsafe exec, and weak crypto get caught without noise. Multi-language `rules.yaml`, index-aware staged-file reads via `git show :<path>`.
